# Library Management System

## 📚 Project Overview
A JavaFX desktop application for managing a library system, built with Object-Oriented Programming principles.

## 🛠️ Built With
- Java
- JavaFX
- OOP Concepts (Encapsulation, Inheritance, Polymorphism, Abstraction)
